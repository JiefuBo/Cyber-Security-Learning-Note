# Security Operations Center (SOC)

## Definition

A Security Operations Center (SOC) is a centralised team and infrastructure responsible for:
- Monitoring security events
- Detecting cyber threats
- Responding to incidents
- Managing security operations
- Protecting organisational systems

SOC teams operate continuously to maintain cybersecurity visibility and defensive readiness.

---

# Purpose of a SOC

## Core Objectives

SOC operations aim to:
- Detect attacks quickly
- Reduce response time
- Improve security visibility
- Minimise business impact
- Coordinate incident response

SOC teams provide continuous monitoring and defensive analysis.

# Threat Detection Methods

## Signature-Based Detection

Detects threats using:
- Known attack signatures
- Predefined patterns
- Malware fingerprints

Advantages:
- Accurate for known threats

Limitations:
- Weak against unknown attacks

---

## Anomaly-Based Detection

Detects abnormal behaviour that deviates from normal activity patterns.

Examples:
- Unusual login activity
- Unexpected traffic spikes
- Abnormal data transfers

Advantages:
- Can detect unknown threats

Limitations:
- Higher false positive rates
