# Introduction to System Security Notes

## Overview

System security focuses on protecting computer systems, networks, applications, and data from unauthorized access, attacks, misuse, and damage. Security principles aim to maintain confidentiality, integrity, and availability of digital assets.

Modern cybersecurity involves technical controls, security policies, risk management, monitoring, and defensive strategies against evolving threats.

---

# Core Security Objectives

## Confidentiality

Confidentiality ensures information is accessible only to authorized individuals or systems.

### Common Protection Methods

- Encryption
- Access control
- Authentication
- Permission management

---

## Integrity

Integrity protects information from unauthorized modification or destruction.

### Protection Mechanisms

- Hashing
- Digital signatures
- File integrity monitoring
- Access restrictions

---

## Availability

Availability ensures systems and services remain accessible when needed.

### Threats to Availability

- Denial-of-service attacks
- Hardware failures
- Malware infections
- Power outages

---

# Cybersecurity Fundamentals

## Definition

Cybersecurity involves protecting systems, networks, applications, and information from cyber threats.

## Main Security Areas

- Network security
- Application security
- Information security
- Endpoint security
- Cloud security
- Operational security

---

# Threats and Attacks

## Malware

Malicious software designed to damage or compromise systems.

### Common Malware Types

- Viruses
- Worms
- Trojans
- Ransomware
- Spyware

---

## Phishing

Phishing attacks trick users into revealing sensitive information.

### Common Targets

- Passwords
- Banking information
- Authentication tokens
- Personal information

---

## Social Engineering

Manipulates human behavior to bypass technical security controls.

### Examples

- Phishing emails
- Fake technical support
- Impersonation attacks
- Tailgating

---

# Authentication and Access Control

## Authentication

Verifies user identity before granting access.

### Authentication Factors

| Factor | Example |
|---|---|
| Knowledge | Password |
| Possession | Security token |
| Inherence | Fingerprint |

---

## Authorization

Determines which resources users can access after authentication.

## Principle of Least Privilege

Users should receive only the minimum permissions required.

---

# Network Security

## Firewalls

Firewalls filter incoming and outgoing network traffic.

## Intrusion Detection Systems (IDS)

Monitor networks for suspicious behavior and attacks.

## Virtual Private Networks (VPN)

Encrypt communication across untrusted networks.

---

# Encryption

## Definition

Encryption converts readable data into protected ciphertext.

## Common Uses

- Secure communication
- Data protection
- Password storage
- VPN traffic protection

## Symmetric Encryption

Uses the same key for encryption and decryption.

## Asymmetric Encryption

Uses public and private key pairs.

---

# Risk Management

## Risk Components

| Component | Description |
|---|---|
| Threat | Potential cause of harm |
| Vulnerability | Weakness in a system |
| Impact | Damage caused by exploitation |
| Risk | Likelihood and consequence of attack |

# Security Policies

## Purpose

Security policies define acceptable usage, controls, and security responsibilities.

## Common Policy Areas

- Password management
- Access control
- Incident response
- Data handling
- Device usage

---

# Incident Response

## Definition

Incident response is the process of handling cybersecurity incidents.

## Main Stages

1. Preparation
2. Detection
3. Containment
4. Eradication
5. Recovery
6. Lessons learned

---

# Security Best Practices

## Recommended Practices

- Regular software updates
- Strong passwords
- Multi-factor authentication
- Data backups
- Security awareness training
- Continuous monitoring

# Summary

- System security protects digital systems and information from threats.
- The CIA Triad forms the foundation of cybersecurity principles.
- Malware, phishing, and social engineering are common attack methods.
- Authentication and authorization control system access.
- Encryption protects sensitive data and communications.
- Risk management and incident response improve organizational security resilience.
- Security best practices reduce exposure to cyber threats.
