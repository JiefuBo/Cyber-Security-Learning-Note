# Security Operations Center (SOC)

## Definition

A Security Operations Center (SOC) is a centralised cybersecurity function responsible for:
- Monitoring systems and networks
- Detecting cyber threats
- Investigating suspicious activity
- Coordinating incident response
- Improving organisational security posture

SOC operations provide continuous visibility into cybersecurity events.

---

# SOC Objectives

## Core Goals

SOC teams aim to:
- Detect attacks rapidly
- Reduce response time
- Minimise security impact
- Improve threat visibility
- Maintain operational resilience

# Threat Detection Methods

## Signature-Based Detection

Detects known attack patterns and malware signatures.

Advantages:
- Accurate for known threats

Limitations:
- Weak against unknown attacks

---

## Behaviour-Based Detection

Identifies suspicious behaviour rather than fixed signatures.

Examples:
- Unusual process execution
- Abnormal login behaviour
- Unexpected network traffic

Advantages:
- Better detection of unknown threats

# Alert Fatigue

## Definition

Alert fatigue occurs when analysts receive excessive security alerts.

Consequences:
- Reduced efficiency
- Missed critical threats
- Increased operational stress

Effective alert prioritisation is essential.
