# Cyber-Security-Learning-Note

Cyber-Security-Learning-Note is a structured collection of cybersecurity study notes. It brings together core concepts, attack and defense techniques, protocol analysis, security operations, and practical tool usage in a numbered learning sequence.

## Overview

The project is designed as a personal cybersecurity knowledge base for reviewing foundational theory and connecting it with applied security practice. The notes cover topics such as network reconnaissance, DNS attacks, TCP/IP security, cryptography, TLS, PKI, intrusion detection, web application security, system hardening, database security, identity and access management, and security operations.

The numbered Markdown files provide a learning path across different areas of cybersecurity. Earlier notes focus on network analysis, DNS behavior, protocol-level attacks, certificates, and firewall concepts. Later notes expand into web security, authentication flaws, SQL injection, vulnerable components, exploitation workflows, operating system security, SOC practices, and common security tools.

## Knowledge Areas

- **Network security**: network reconnaissance, TCP/IP attacks, DNS spoofing, DNS pharming, VPNs, firewalls, and wireless security.
- **Cryptography and trust**: SSL/TLS, X.509 certificates, public key infrastructure, and transport-layer protection.
- **Security monitoring**: intrusion detection, Snort, SOC concepts, network traffic analysis, and operational security workflows.
- **Web and application security**: web security fundamentals, SQL injection, authentication flaws, sensitive data exposure, vulnerable components, and implementation security.
- **System and database security**: operating system security, system hardening, database protection, access control, and identity management.
- **Tools and practice**: Nmap, Wireshark, Metasploit, exploitation concepts, security roles, and industry-oriented security notes.

## How to Use

- Open `index.html` for a searchable navigation page.
- Read the numbered Markdown files in sequence for a broad learning path.
- Jump directly to a specific topic when reviewing a concept, tool, or attack category.
- Use the notes as a reference while studying labs, preparing reports, or reviewing cybersecurity fundamentals.
