Main areas covered:
- Firewall security concepts
- Juniper security policies
- Access control mechanisms
- Network traffic filtering
- Phishing attacks
- Social engineering techniques

---

# Network Security Fundamentals

## Purpose of Network Security

Network security protects systems, devices, and communication channels against:
- Unauthorised access
- Data theft
- Malware infections
- Network attacks
- Information leakage

Effective security mechanisms help maintain:
- Confidentiality
- Integrity
- Availability

---

# Firewall Fundamentals

## Purpose of Firewalls

A firewall controls network traffic entering and leaving a system or network.

Firewalls enforce:
- Security policies
- Access restrictions
- Traffic filtering rules

---

# Firewall Traffic Filtering

## Packet Filtering

Firewalls inspect network traffic based on:
- Source IP address
- Destination IP address
- Port numbers
- Protocol types
- Application types

Filtering helps block:
- Unauthorised communication
- Malicious traffic
- Suspicious network activity

---

# Security Zones

## Concept

Security zones divide networks into separate trust levels.

Examples:
- Internal zone
- External zone
- DMZ (Demilitarised Zone)

Traffic moving between zones is controlled by firewall policies.

---

# Access Control Policies

## Purpose

Security policies define:
- Which traffic is allowed
- Which traffic is denied
- Which applications may communicate

Policies improve:
- Network segmentation
- Access management
- Security enforcement

---

# Application-Based Filtering

## Concept

Modern firewalls identify traffic based on applications rather than only ports.

Examples:
- HTTP
- HTTPS
- SSH
- Telnet

Application-aware filtering improves traffic visibility and security control.

---

# Principle of Least Privilege

## Security Principle

Users and systems should only receive the minimum access necessary to perform required tasks.

Benefits:
- Reduced attack surface
- Improved access control
- Reduced risk of compromise

---

# Phishing Attacks

## Concept

Phishing attacks attempt to trick users into revealing:
- Passwords
- Financial information
- Personal data
- Authentication credentials

Attackers commonly impersonate trusted organisations or individuals.

---

# Social Engineering

## Purpose

Social engineering manipulates human behaviour to bypass technical security controls.

Attackers exploit:
- Trust
- Fear
- Urgency
- Curiosity

---

# Email-Based Threats

## Common Techniques

Phishing emails may contain:
- Fake login pages
- Malicious attachments
- Fraudulent links
- Spoofed sender addresses

Attackers often imitate:
- Banks
- Universities
- Government agencies
- Corporate services

---

# Spear Phishing

## Concept

Spear phishing targets specific individuals or organisations using personalised information.

Characteristics:
- Highly targeted
- More convincing
- Often harder to detect

---

# Email Spoofing

## Concept

Email spoofing falsifies sender information to make messages appear legitimate.

Attackers impersonate trusted senders to:
- Gain user trust
- Increase click rates
- Deliver malicious content

---

# Indicators of Phishing

## Warning Signs

Suspicious indicators may include:
- Urgent language
- Unexpected attachments
- Suspicious URLs
- Grammar mistakes
- Requests for credentials
- Fake domain names

---

# Credential Theft

## Objective

Many phishing attacks aim to steal:
- Usernames
- Passwords
- Authentication tokens
- Financial details

Compromised credentials may lead to:
- Account takeover
- Data breaches
- Identity theft

---

# Malware Delivery

## Risk

Phishing emails may deliver:
- Ransomware
- Keyloggers
- Trojans
- Spyware

Malware infections may compromise entire systems or networks.

---

# Defensive Security Measures

## Email Security Protections

Recommended protections include:
- Spam filtering
- Email authentication
- URL scanning
- Attachment sandboxing
- Multi-factor authentication (MFA)

---

# User Awareness Training

## Importance

Security awareness training helps users:
- Identify phishing attempts
- Recognise suspicious behaviour
- Avoid malicious links
- Report security incidents

Human awareness is a critical cybersecurity defence layer.

---

# Multi-Factor Authentication (MFA)

## Purpose

MFA requires additional verification beyond passwords.

Examples:
- Authentication apps
- SMS verification
- Security tokens
- Biometrics

MFA reduces risks from stolen credentials.

---

# Security Monitoring

## Threat Detection

Security teams monitor:
- Suspicious login activity
- Network traffic anomalies
- Email threats
- Authentication failures

Continuous monitoring improves incident response capability.

---

# Incident Response

## Purpose

Incident response processes help organisations:
- Detect attacks
- Contain threats
- Investigate incidents
- Recover affected systems

Rapid response reduces operational impact.

---

# Security Risks

## Potential Consequences

Phishing and network attacks may result in:
- Credential compromise
- Financial loss
- Malware infections
- Data breaches
- Service disruption
- Reputation damage
