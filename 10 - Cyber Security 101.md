# Cybersecurity Fundamentals

## Definition

Cybersecurity refers to the protection of:
- Computer systems
- Networks
- Applications
- Devices
- Data

from:
- Unauthorised access
- Cyber attacks
- Data breaches
- System compromise
- Malicious activity

---

# Information Security Objectives

## CIA Triad

The core security objectives are represented by the CIA Triad.

### Confidentiality

Protects information from unauthorised disclosure.

Examples:
- Encryption
- Access control
- Authentication

---

### Integrity

Ensures information remains accurate and unmodified.

Examples:
- Hashing
- Digital signatures
- File integrity monitoring

---

### Availability

Ensures systems and data remain accessible when needed.

Examples:
- Redundancy
- Backups
- Disaster recovery systems

---

# Authentication and Authorisation

## Authentication

Authentication verifies identity.

Common methods:
- Passwords
- Biometrics
- Multi-factor authentication

---

## Authorisation

Authorisation determines what actions users are allowed to perform after authentication.

Examples:
- Access permissions
- Role-based access control
- Security policies

# Cyber Threats

## Common Threat Categories

Cyber threats include:
- Malware
- Phishing
- Ransomware
- Denial-of-service attacks
- Insider threats
- Social engineering
- Credential theft

---

# Malware

## Definition

Malware is malicious software designed to:
- Damage systems
- Steal information
- Disrupt operations
- Gain unauthorised access

---

## Malware Types

### Virus
Requires user interaction to spread.

### Worm
Self-replicates across networks automatically.

### Trojan
Disguises itself as legitimate software.

### Ransomware
Encrypts files and demands payment.

### Spyware
Secretly monitors user activity.

---

# Phishing and Social Engineering

## Phishing

Phishing attacks attempt to trick users into revealing:
- Passwords
- Financial information
- Personal data

Attackers commonly use:
- Fake emails
- Fraudulent websites
- Malicious links

---

## Social Engineering

Social engineering manipulates human behaviour to bypass technical security protections.

Attackers exploit:
- Trust
- Fear
- Urgency
- Curiosity

---

# Vulnerabilities

## Definition

A vulnerability is a weakness that attackers may exploit.

Examples:
- Weak passwords
- Unpatched software
- Misconfigured systems
- Insecure protocols

---

# Risk Management

## Concept

Risk management identifies and reduces cybersecurity risks.

Main steps:
1. Identify threats
2. Assess vulnerabilities
3. Evaluate risks
4. Apply controls
5. Monitor systems

---

# Security Controls

## Administrative Controls

Policies and procedures designed to improve security.

Examples:
- Security awareness training
- Access policies
- Incident response plans

---

## Technical Controls

Technology-based security protections.

Examples:
- Firewalls
- Antivirus software
- Encryption
- IDS/IPS systems

---

## Physical Controls

Protect physical systems and infrastructure.

Examples:
- Locks
- CCTV systems
- Security guards
- Access cards

---

# Network Security

## Purpose

Network security protects communication infrastructure and connected devices.

Common protections:
- Firewalls
- Intrusion detection systems
- VPNs
- Traffic monitoring

---

# Encryption

## Purpose

Encryption protects data confidentiality by converting readable data into unreadable ciphertext.

Encryption protects:
- Stored data
- Network communication
- Authentication credentials

---

# Access Control

## Principle of Least Privilege

Users should receive only the minimum access required to perform their tasks.

Benefits:
- Reduces attack surface
- Limits damage from compromise
- Improves security management

---

# Incident Response

## Purpose

Incident response manages cybersecurity incidents effectively.

Main phases:
1. Preparation
2. Detection
3. Containment
4. Eradication
5. Recovery
6. Lessons learned

---

- Recognise phishing attacks

- Protect sensitive data
- Report suspicious activity
